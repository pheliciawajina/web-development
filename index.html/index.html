About QuickNotes

QuickNotes is a simple app for capturing thoughts, to-dos, and ideas the moment they come to you. It stays fast and clutter-free so you can write first and organise later.

How to use QuickNotes

  1. Open QuickNotes and select New note.
  2. Type a title and write your note.
  3. Select Save to keep it.
  4. Use the search box to find a note later.
  5. Open a note to edit it, or select Delete to remove it.

Features

  • Create a note in one click
  • Edit and delete notes anytime
  • Search across all your notes
  • Works on phone, tablet, and laptop

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
Ctrl + D Delete the current note
